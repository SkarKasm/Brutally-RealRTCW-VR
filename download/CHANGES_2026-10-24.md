# Brutally RealRTCW VR: October 24 test build (single player co-op)

A test build that hasn't been played yet. The October 18 update stays the main download until this one has been tried.

## One download for everything
Single player and the older RealRTCW co-op mode are now in one zip, with all their launchers and both READMEs. Everyone who plays together needs this same download. Mixed versions of the mod stop joining with "Could not download coop_EE/z_vr_assets.pk3".

## Single player co-op (new)
The single player campaigns with a friend, running on the single player game itself, so the cutscenes, scripts, controls and gore are the single player ones.
- **Host:** start `SP co-op host VR.bat` (or the Cursed Sands one, or the `(no VR)` ones) and start a NEW GAME. Keep Steam running.
- **Join:** start `SP co-op join VR.bat`, or use Join Game in the Steam friends list. The game switches to the host's campaign by itself, and nothing needs setting up.
- Cutscenes, videos and music play for everyone. Only the host can skip them.
- The joining player appears next to the host, carrying the host's weapons. Whoever goes down comes back next to the other player a few seconds later. The game only goes back to the checkpoint when everyone is down.
- Every player in a headset has their own hands: manual reloading, grabbing bodies and props, the knife, doors and buttons, and dual guns.
- The host saves and loads as usual. Saves made in normal single player can't be loaded in co-op, so start co-op with NEW GAME.
- Console: `hostcoop <map>` starts a co-op game on any map, and `steamjoin [name]` joins a friend.

Network protocol 51: builds before this one can't connect to it. Existing single player saves still load.
